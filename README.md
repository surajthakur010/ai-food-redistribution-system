# 🍽️ AI-Based Smart Food Waste Redistribution System for College Campuses

### A Surplus Prediction and NGO Matching Approach

---

## 📌 Overview

Food waste is a major issue in college campuses, while many people still struggle to access food. This project presents an AI-based solution that predicts surplus food and redistributes it efficiently to NGOs.

The system uses data-driven techniques to forecast excess food generation and intelligently matches it with NGOs to ensure timely distribution. This helps reduce food wastage and supports social welfare.

---

## 🎯 Objectives

* Predict surplus food using AI/ML techniques
* Reduce food wastage in college campuses
* Connect campuses with NGOs for redistribution
* Create a scalable and sustainable solution

---

## ⚙️ Features

* 🔍 **Surplus Food Prediction** using machine learning
* 🤝 **NGO Matching System** for efficient redistribution
* 📊 Data-driven decision making
* 🌱 Promotes sustainability and social impact
* 📁 Easy-to-use and modular structure

---

## 🧠 How It Works

1. Collect historical food consumption data
2. Apply ML model to predict surplus food
3. Identify available NGOs
4. Match surplus food with suitable NGOs
5. Ensure timely redistribution
